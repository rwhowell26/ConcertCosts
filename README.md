# Concert Cost Tracker

Track concerts you attended, what you spent, and how much fun you had.

## Run locally

1. Make sure `.env.local` has your Supabase Project URL and anon (or publishable) key.
2. Install packages: `npm install`
3. Start the app: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)

## Stack

Next.js, React, Tailwind CSS, daisyUI, Supabase Auth + Database, Recharts
